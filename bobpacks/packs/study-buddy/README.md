# Study Buddy

**Audience:** Students · **Level:** Beginner · **Integrity stance:** Hints only

Turn any code, notes or lecture material into quizzes, flashcards or concept summaries — in seconds.

## What's included

| Component | What it does |
|---|---|
| `study-buddy` skill | Auto-triggers when you ask to study, quiz yourself or revise a topic |

## Install

```bash
npx bobpacks add study-buddy
```

## Usage

Share anything — a function, a set of notes, a topic name:

```
Quiz me on recursion
```
```
Make flashcards from these notes: [paste notes]
```
```
Summarize what this class does: [paste code]
```

Bob will ask which format you want (quiz, flashcards, concept summary, or explain-back) and generate it.

## Integrity stance

Hints only — quizzes reveal the answer only after you respond.

## Uninstall

```bash
npx bobpacks remove study-buddy
```
