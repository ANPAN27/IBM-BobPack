# Assignment Planner

**Audience:** Students · **Level:** Beginner · **Integrity stance:** Hints only

Give Bob an assignment brief and get back a task list, file structure and empty function stubs — not a finished solution.

## What's included

| Component | What it does |
|---|---|
| `assignment-planner` skill | Auto-triggers when you share an assignment description |
| `AGENTS.snippet.md` | Adds context to AGENTS.md so Bob knows its role on this project |

## Install

```bash
npx bobpacks add assignment-planner
```

## Usage

Paste the assignment description into chat. Bob will:
1. List every deliverable
2. Break it into ordered tasks
3. Create empty starter files with function stubs and test placeholders

You write the implementation. Bob keeps you on track.

## Integrity stance

Hints only. Bob creates stubs and plans but writes no implementation code during the planning step.

## Uninstall

```bash
npx bobpacks remove assignment-planner
```
