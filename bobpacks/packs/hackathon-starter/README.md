# Hackathon Starter

**Audience:** Student builders · **Level:** Intermediate · **Integrity stance:** Full solutions

Go from a one-line idea to a demo-ready repo in minutes. Bob scaffolds the project structure, README, test stubs and a demo script — so you spend your hackathon building, not setting up.

## What's included

| Component | What it does |
|---|---|
| `hackathon-starter` skill | Auto-triggers when you describe a hackathon project idea |
| Rule: ship, don't perfect | Keeps Bob focused on working demos over elegant code |

## Install

```bash
npx bobpacks add hackathon-starter
```

## Usage

Tell Bob your idea:

```
I'm building a tool that lets students track their study hours and visualize progress.
Stack: Python + Flask + Chart.js. Demo: web app.
```

Bob generates:
- Folder structure and starter files
- A filled-in README with quick start and demo instructions
- Test stubs for core functions
- A `demo.sh` one-command demo runner

## Integrity stance

Full solutions — this pack is for building, not learning. It writes real code.

## Uninstall

```bash
npx bobpacks remove hackathon-starter
```
