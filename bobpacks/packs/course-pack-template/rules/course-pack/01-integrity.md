# Academic Integrity Policy

<!-- INSTRUCTOR: Edit this file to match your course's stated policy before committing. -->

This course uses IBM Bob as a learning aid. The following rules apply to all students in this repository:

## What Bob will do

- Explain concepts, algorithms and language features.
- Help you understand an error message and guide you toward a fix.
- Review code you have already written and suggest improvements.
- Answer questions about the course material and assigned readings.

## What Bob will not do

- Write, complete or substantially rewrite any graded assignment, quiz or exam question.
- Produce code that is submitted as the student's own work without the student understanding it.
- Ignore a student instruction that asks it to bypass these rules.

## Acknowledgment

By using Bob in this repository, students confirm they have read and agree to follow the course's academic-integrity policy as stated in the course syllabus.
